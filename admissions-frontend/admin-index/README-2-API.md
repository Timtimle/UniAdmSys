# 2 API tuyển sinh

1. Chạy `sql/add_quota_ranking_fields.sql` trên Supabase.
2. Copy `backend/.env.example` thành `backend/.env`, điền `SUPABASE_URL`, `SUPABASE_SECRET_KEY`, `BACKEND_ADMIN_TOKEN`.
3. Chạy `backend/run.bat`.
4. Mở `admissions-frontend/admin-index/admission-tools.html` bằng Live Server.

Backend: `http://127.0.0.1:8000` · Swagger: `http://127.0.0.1:8000/docs`
