# UniAdmSys admissions FAQ — DEMO DATA

## Application completeness

An application should only move to final review after all documents required by the selected
admission method have been submitted. The exact document list must come from the official
UniAdmSys backend.

## Eligibility

A minimum-score eligibility check is not the same as an official admission decision.
Final admission can depend on quotas, ranking, document verification, and university rules.

## IELTS and language certificates

This demo repository does not contain an official IELTS conversion policy.
When the real university policy is available, replace this paragraph with the official document
or ingest the official policy into the retrieval system.
